# Desapega Turbo — Landing Page

Landing recuperada do HTML salvo no navegador, com servidor Bun e proxy de imagens em `/dt-image/:id`.

## Executar

```bash
bun run start
```

A Railway fornece a variável `PORT`. Não publicar credenciais no repositório público.

> O aplicativo e o Radar são serviços separados na Railway e não fazem parte deste repositório neste momento.
